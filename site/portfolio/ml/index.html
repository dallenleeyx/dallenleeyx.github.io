    Linear regression from scratch

    Fit a line to a small dataset with gradient descent, then compare the implementation with PyTorch.

    Method
    Mean squared error · gradient descent
    Data
    Synthetic, for demonstration
    View sample code

    This short example shows the kind of code that can accompany a project. It is not a completed personal project.

    import torch

x = torch.linspace(-1, 1, 21).reshape(-1, 1)
y = 1.8 * x + 1
model = torch.nn.Linear(1, 1)
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)

for _ in range(200):
    loss = ((model(x) - y) ** 2).mean()
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
