Linear regression from scratch

Sample notebook using synthetic data.

Fit a line to data using gradient descent, with a small PyTorch implementation.

The model

The training data follows y = 1.8x + 1. The model learns a weight and bias by minimising mean squared error.

PyTorch implementation

import torch

# Illustrative example using synthetic data.
x = torch.linspace(-1, 1, 21).reshape(-1, 1)
y = 1.8 * x + 1
model = torch.nn.Linear(1, 1)
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)

for _ in range(200):
    loss = ((model(x) - y) ** 2).mean()
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

print('Weight:', model.weight.item())
print('Bias:', model.bias.item())
